# TEMPLE of Time
**Timescales of Experience: Motor, Perceptual & Latency of Executive-function**

> A mobile-first, gamified psychophysics web application designed to evaluate multi-scale time perception, sensorimotor dynamics, and executive function latencies.

---

## Paradigm Suite

The platform integrates cognitive-behavioral paradigms including:
- **Perceptual Timing:** Simultaneity Judgement (SJ) and Temporal Order Judgement (TOJ) task.
- **Motor Control & Timing:** Spontaneous Motor Tapping (SMT) and Time Production tasks.
- **Executive Function & Decision Making:** Delay Discounting and Multi-Source Interference Task (MSIT).
- **Agency:** Sense of Agency (SoA) task.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Modular ES6+)
- **Styling:** Custom CSS / Tailwind CSS
- **Backend & Storage:** Supabase (Cloud database integration with Row-Level Security policies and anonymous client authentication)
- **Deployment:** Static hosting compatible (GitHub Pages / Netlify / Vercel)
